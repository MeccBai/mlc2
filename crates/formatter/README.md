# mlc_formatter

唯一入口：`format(&str) -> Result<String, FormatError>`。不提供排版配置，
不做符号重命名、语义分析或 import 加载，也不写文件。

```rust
let output = mlc_formatter::format("func main(){var x=1;}")?;
```

复用 mlc_syntax 的 lexer（token、注释及原始 span）和完整 chumsky parser。
词法或 Temp AST 解析失败时返回诊断，不输出部分结果。首版以通过验证的 token
流作为输出骨架，保留全部 token、字面量拼写及注释原文，只调整 token 间空白。
无需再实现一套 chumsky 语法，也不使用面向调试的 Temp AST dump。

注释按原始 token 间隙线性合并，包括文件头尾和空块；行尾注释仍留在原 token
之后，单行注释强制换行。固定四空格缩进、LF 行尾、非空文件末尾换行，花括号
内容按固定规则排版。不重排、增加或删除 token。
多行字符串和块注释内容保持原样，因此它们内部的行尾不被规范化。

返回前重新词法分析并检查 token 与注释序列，避免格式化静默改变源码。
排版算法、AST 布局提示和错误类型分别位于独立模块；
命名规范检查不属于格式化配置。CLI 的检查模式、写回和批量遍历由调用方负责。

## 固定列表规则

- 函数声明/调用、宏参数和泛型参数：内容超过 30 字符则一行一个。
- 宽度是原 token 文本的 Unicode 字符数之和：不计 token 间空白、缩进或外层
  括号，不计函数/类型名字；参数内部的类型标记、标点和分隔逗号计入，字符串
  字面量自身的空格计入。等于 30 不展开。
- Unit 成员、Union 候选各一行；每组 `#[attribute]#` 始终独占一行。
- InitList、数组和管道参数包：不超过 30 时单行，超过则按完整元素装行，
  每行计数不超过 30；无法拆分的单个超长元素允许超宽。
- 嵌套列表独立布局；单参数调用保留 `add(One { ... });` 的连接形式。
- `if`、`else`、`for`、`while` 的左花括号与头部同行；`else` 与前一个右花括号同行。
- 右花括号与调用结束 `);`、管道 `|>` 保持连接。尾逗号、分号只保留，不增删。
- 单行或独立行注释可迫使所在列表展开；注释文本不折行。
- 顶层 Unit/Union/Generic 后空一行；函数、接口和宏函数后空两行。
  连续 import/export import/export using 作为一组，组后空两行。
  行尾注释保持附着，下一声明的独立行注释放在空行之后；文件尾不追加空白行。
